## Historia
Como persona que completa un formulario de SIGPRO con un lector de pantalla o con poca vista, quiero que cada campo tenga una etiqueta visible y que cada aviso de error aparezca junto al campo al que se refiere, con el foco en el primero que falla,
para saber qué pide cada campo y corregirlo sin buscarlo.

## Reglas
- Cada campo tiene su etiqueta visible, y el lector lo anuncia con esa misma etiqueta.
- El texto de ejemplo que aparece dentro de un campo vacío es distinto de la etiqueta y nunca la sustituye: un campo sin etiqueta visible no cumple aunque tenga ese ejemplo.
- Un aviso de error de un campo aparece debajo de ese campo, y el lector lo anuncia al llegar al campo: se oye la etiqueta y, después, el aviso.
- Si al enviar un formulario hay campos con error, el foco va al primero de ellos en el orden del formulario, y no al botón de envío.
- Preparación de cada fila: se reinicia el tenant `alumno01` con `POST /api/admin/reset` y el token de `alumno01@sigpro.lab` (contraseña `Alumno1234!`). Los formularios se abren en un navegador sin sesión guardada, con los campos vacíos salvo lo que indique la fila.

## Fuera de alcance
- Las reglas de validación y el texto de cada formulario concreto (acceso, solicitud de acceso, alta de programas y resto de módulos): las épicas de cada formulario.
- Los avisos de error del servidor que aparecen encima de un formulario: US-A11Y-006.
- Los avisos emergentes que se retiran solos: EP-TOASTS.
