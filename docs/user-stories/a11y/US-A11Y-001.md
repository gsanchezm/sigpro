## Historia
Como persona que usa SIGPRO con un lector de pantalla, quiero que cada control, cada campo y cada imagen tenga un nombre que el lector anuncie,
para saber qué hace cada botón, a qué fila pertenece y qué muestra cada imagen sin verla.

## Reglas
- Todo control que se puede pulsar, marcar, seleccionar o escribir se anuncia con un nombre que dice qué hace. Si el control es solo un icono o un signo, el nombre lo dice con palabras.
- Cuando la acción recae sobre una fila de una lista, el nombre incluye el código de la fila: «Acciones para PRG-001» y no solo «Acciones».
- Dos controles de una misma pantalla que hacen cosas distintas no se anuncian con el mismo nombre.
- Cada imagen tiene un texto alternativo que dice lo que muestra: el logotipo se anuncia como «SIGPRO»; el avatar de una persona, con su nombre, aunque ese nombre esté escrito también al lado; una miniatura de evidencia, con el código del caso de prueba al que pertenece.
- Un control que cambia de función según su estado, como el que muestra u oculta la contraseña, se anuncia con el nombre del estado en el que está (ver «Decisiones pendientes»).
- Preparación de cada fila: se reinicia el tenant `alumno01` con `POST /api/admin/reset` y el token de `alumno01@sigpro.lab` (contraseña `Alumno1234!`). Las filas que piden una sesión la inician después con la cuenta y el tenant de la fila, desde un navegador sin sesión guardada.

## Decisiones pendientes
- Si el control que muestra u oculta la contraseña conserva un nombre fijo y anuncia su estado aparte, o si su nombre cambia entre «Mostrar contraseña» y «Ocultar contraseña». Hasta que se decida, esta historia solo afirma el nombre del control mientras la contraseña está oculta.

## Fuera de alcance
- El texto y la función de cada control concreto: la épica de la pantalla en la que vive.
- El contraste de los textos y de los controles en los dos temas: EP-TEMA (US-TEMA-006).
- Las secciones que muestra cada entrada de la barra lateral y de la barra inferior de la app móvil: EP-NAVEGACION (US-NAVEGACION-011).
