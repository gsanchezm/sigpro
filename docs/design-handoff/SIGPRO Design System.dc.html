SIGPRO · DESIGN SYSTEM v0.1

Sistema de diseño SIGPRO

Interfaz técnica y densa para gestión de programas de ingeniería de sistemas. Tipografía IBM Plex Sans / Mono, paleta gris azulada con un único acento azul, badges de estado de alto contraste. Sin ilustraciones ni degradados. Cada elemento interactivo lleva nombre accesible y data-testid con patrón pantalla-elemento.
